# EU AI Operator Desk — Regional Layer

The operator desk uses a Europe-first localization model while keeping the operating language neutral and provider-independent.

## Language tiers

- `bg-BG` — Bulgaria / home market; primary local-language experience.
- `en-GB` — European and international operating language; default cross-border language.
- `de-DE` — DACH expansion.
- `fr-FR` — France / Francophone EU expansion.
- `pl-PL` — Poland / CEE expansion.
- `ro-RO` — Romania / CEE expansion.
- `cs-CZ` — Czechia / CEE expansion.
- `sk-SK` — Slovakia / CEE expansion.
- `hu-HU` — Hungary / CEE expansion.

## Regional tiers

1. Bulgaria — Sofia/EU entry layer; Bulgarian + English.
2. EU — regulatory, data-residency and cross-border operating layer.
3. CEE — localized language, partner and market layer.
4. UK — English/GBP operating layer for UK expansion.
5. Global — English-first interoperability layer.

Regionalization must cover language, locale-safe dates/numbers, currency, timezone, tax/VAT context, payment methods, legal copy, support routing and evidence/operating-state terminology.

No region should silently change provider, data boundary, pricing, tax treatment or authorization policy. Those are explicit configuration decisions.
